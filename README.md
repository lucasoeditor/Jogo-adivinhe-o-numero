# 🎯 Jogo: Adivinhe o Número

Uma aplicação simples em JavaScript onde o jogador precisa adivinhar um número secreto gerado aleatoriamente. O jogo fornece dicas a cada tentativa até que o número correto seja descoberto.

## 🚀 Funcionalidades

* Geração de número aleatório
* Campo para inserir palpites
* Feedback automático:

  * Número maior 🔼
  * Número menor 🔽
  * Acertou ✅
* Validação de entrada inválida
* Reinício do jogo após vitória

## 💡 Lógica básica

* O sistema gera um número aleatório dentro de um intervalo definido
* O jogador tenta adivinhar o número
* A cada tentativa, o sistema informa se o número correto é maior ou menor
* O jogo termina quando o jogador acerta o número
